# 后端可靠性修复

基于 `1083af4203676f7276d6e0744a8cf047c19288c1`，保留 Electron 主进程服务结构、三个产品身份和既有打包配置。

## 行为变化

- IPC 包装器转发全部参数，并等待异步处理器；单个音源的启用状态与拖放选项不再丢失。
- 设置的读取、更新返回值、重置和广播使用公开视图，只提供 `ai.hasKey`；密钥只供主进程服务使用。
- 配置写入排队执行，在同目录写完整临时文件、同步文件内容后原子替换，并保留上一版有效 JSON。
  读取损坏文件时保留原件并尝试恢复备份；权限和 IO 错误明确失败，不静默当成新用户。
  IPC 保存等待落盘，失败返回错误并向界面发出保存失败提示。音乐库缓存同样改用原子替换。
- 字幕校正/翻译缓存包含完整提示词与接口地址；语言、歌曲上下文、模型和接口改变都会使缓存失效。
- 音源脚本迁入独立工作线程的 QuickJS/WASM 解释器；主进程、线程与解释器之间交换序列化数据，
  不把 Node 函数、Buffer 实例或错误原型直接交给脚本。保留常用 CommonJS/LX 音源接口。
  脚本超时会终止对应线程并取消其网络请求；删除、重载和退出也释放运行器。
  从链接导入及脚本请求均有 HTTP/HTTPS 协议限制、超时和响应体积限制。

## 验证入口

```bash
npm ci
npm run check
npm run test:backend
npm run test:backend:electron
```

后端测试不需要桌面，已接入原有 CI。Electron 集成检查需要桌面，在独立临时用户目录中启动真实应用，
通过真实 preload/IPC 验证设置、密钥输入框、音源与字幕缓存；只使用合成数据和本机 HTTP 服务。
截图放在 `.tmp/backend-electron/`，不覆盖项目原有截图。

Linux 无桌面时可使用 `xvfb-run -a`。用 `ARIA_PRODUCT=player` 或 `ARIA_PRODUCT=unified` 选择产品；
Unified 播放器模式追加 `--profile=player`。修改音源运行器时还应验证 ASAR 内依赖与解包后的 worker 能一起加载。

## 边界

QuickJS 不提供 Node/文件系统/进程接口，但脚本可通过指定接口请求 HTTP/HTTPS，包括本机或内网服务；
这不是网络目的地址隔离。外部搜索器是用户配置的本机程序，不在脚本解释器里运行。
资源上限及兼容 API 详见 [EXTENDING.md](EXTENDING.md)。

配置仍是本机明文文件；新增文件使用 `0600` 权限（实际访问控制由操作系统决定），备份也包含配置数据。
原子替换用于避免中途退出留下半份 JSON，不代替设备级备份或所有文件系统上的断电恢复保证。
本次没有打 Windows/macOS 安装包，也没有更改版本号；lock 文件根版本同步到了原有 `package.json` 的 `0.1.0`。
